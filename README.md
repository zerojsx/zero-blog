# Zero Blog

Memoria editorial compartida para preparar, investigar, enseñar, redactar y revisar artículos de **ZeroJSX**.

Este repositorio guarda criterios **reutilizables**, aprendizajes por temática y decisiones verificadas de cada publicación. El material fuente, los borradores y los artículos pueden seguir viviendo en Google Drive; acá se guarda el contexto para que ChatGPT, Claude u otros agentes trabajen de forma consistente.

## Empezar

1. Leer [AGENTS.md](AGENTS.md) e [INDEX.md](INDEX.md).
2. Abrir la [skill de Zero Blog](skills/zero-blog/SKILL.md) y elegir el flujo necesario: investigación, dossier de estudio, brief, artículo o revisión.
3. Consultar los criterios generales en `docs/` y después la ficha del tema en `topics/`.
4. Al terminar, actualizar solamente el conocimiento estable que haya surgido del trabajo y dejar un registro breve en `memory/LOG.md`.

## Estructura

| Ubicación | Para qué sirve |
| --- | --- |
| `AGENTS.md` | Instrucciones comunes de operación y actualización para agentes |
| `INDEX.md` | Router de lectura: qué consultar según la tarea |
| `skills/zero-blog/SKILL.md` | Procedimiento de producción y revisión editorial |
| `docs/` | Voz, pedagogía e investigación agnósticas al tema |
| `templates/` | Guías flexibles para dossiers y criterios de artículos |
| `topics/` | Índices de temas, enlaces a Drive y lecciones particulares |
| `memory/DECISIONS.md` | Decisiones aceptadas que siguen vigentes |
| `memory/LOG.md` | Hitos mínimos: fecha, cambio y motivo |

## Principios

- **Primero comprender; después escribir.** El dossier debe enseñar al editor sin exigir experiencia previa en el tema.
- **Explicar antes de nombrar.** Situación cotidiana → funcionamiento → término técnico → aplicación, cuando ayude.
- **Separar fuentes y ejemplos.** Una hipótesis didáctica no es un dato observado.
- **No imponer un molde.** Definir qué debe comprender el lector final; dejar margen al autor para encontrar la estructura.
- **Persistir aprendizajes, no conversaciones enteras.** Cada regla duradera tiene un lugar claro y un log conciso.

**Cuenta de GitHub para este repositorio:** `zerojsx`. Para escribir en GitHub, verificar la cuenta conectada y los permisos; no asumir que otra sesión tiene el mismo acceso.

La fuente de verdad de los artículos y su estado editorial debe consultarse en Drive; la presencia de un enlace en este repositorio **no confirma que esté publicado**.
